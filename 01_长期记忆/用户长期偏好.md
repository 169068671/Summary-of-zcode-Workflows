# 用户长期偏好

> [!important] 记录原则
> 只保存用户已明确确认、能跨项目复用的偏好。

## 沟通

- 默认使用中文。
- 先给结果，再补充必要说明。
- 执行中需要简短告知进度，不让任务长时间无反馈。
- 面向用户的交付尽量非技术化，但在调试或核对时保留必要技术证据。

## 执行

- 对已确认的任务主动执行并完成验证。
- 涉及新的付费调用时，先核对模型、参数、余额和预计成本；避免网络慢造成重复提交。
- 对已提交的异步任务保存任务 ID，只轮询原任务。
- 交付文件时提供可点击的本地路径。

## Git 推送

- **GitHub 使用 SSH 推送**（HTTPS 会 408 超时）。
  - SSH remote 名称：`github-ssh`
  - SSH 地址：`git@github.com:169068671/Teaching-and-Research-Data-Warehouse.git`
  - SSH key：`~/.ssh/id_ed25519`（已添加到 GitHub 账户 169068671）
  - 推送命令：`git push github-ssh main --force`
- **Gitee 使用 SSH 推送**。
  - SSH remote 名称：`gitee`
  - 推送命令：`git push gitee main`
- **大文件处理**：
  - GitHub：直接作为普通 git 对象推送（无容量限制，但单次推送 <100MB 更稳定）。
  - Gitee：免费版仓库 100MB 总量限制，不支持 LFS；企业版仓库支持 LFS。
  - 超大文件（如 FreeCAD 课题包 85MB）可排除或用 LFS。
- 推送时用北京时间（系统时区已为 CST）。
- 两个仓库都推送到 main 分支。
