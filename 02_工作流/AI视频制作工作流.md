# AI 视频制作工作流

## 标准链路

1. 确认人物锚点组，从中选定并记录本项目锚点，同时确认场景、时长、画幅、分辨率、音频和预算。
2. 锁定连续性：人物、服装、发型、眼镜、道具、空间、机位、光线和色温。
3. 完成脚本、分镜和专业提示词。
4. 先制作并审核主关键帧，通过后才提交视频。
5. 提交前查询模型实时能力、价格、余额和参数。
6. 每个镜头只提交一次，保存任务 ID 并轮询原任务。
7. 成功后立即下载，检查人脸、年龄、表情强度、手部、道具、物理常识、声音和镜头连续性。
8. 只补做问题镜头，不重复已合格的生成。
9. 交付成片、抽帧验收图、提示词、任务 ID 和成本记录。

## 上传锚点与原始锚点分层

- 原始人物、场景和品牌锚点是本地生产母版，用于图片生成、精修、连续性核验和成片验收；不得被小图反向覆盖。
- GitHub 上传、在线预览和 Obsidian Markdown 展示只使用从原图派生的“上传锚点”：最长边 1600 像素、JPEG、单张不超过 2 MB。
- 原图与上传锚点必须一一对应，并记录双方路径、SHA-256、尺寸和体积；任一哈希不一致时禁止同步。
- 所有 AI 视频知识库的同步脚本必须忽略原始锚点目录，只跟踪 `attachments/上传锚点/`。

## 音乐卡点视频

需要按歌词、拟声词、强音或鼓点精确切镜时，必须使用 [[音乐卡点AI视频制作工作流]]：先用人耳确认语义卡点并量化到输出帧；人物关键帧与最终同框图全部审核、下载落盘后，才进入视频生成；成片必须用实际场景切点反查，不能只相信自动节拍检测或剪辑脚本中的计划时间。

做「爱的主打歌 / 豆志刚 / 权谋群像环绕」这类片时，额外遵循 [[爱的主打歌群像环绕运镜]]：低机位持续环绕或阶梯后拉、C 位虚实出场、强音第一帧完成群像揭示。

## 丁美霞项目

开始前必须读取 [[../01_长期记忆/重要人物与数字资产#双图核验清单（必用）|丁美霞双图核验]]、[[../01_长期记忆/重要人物与数字资产#唯一主锚点（不变）|唯一主锚点]] 和 [[../01_长期记忆/丁美霞状态参考体系]]。

> [!danger] 双图强制核验
> 关键帧与成片抽帧必须同时对照：**① 4K 主锚点**（身份）+ **② 脸型核验 8 格**（瘦削度）。缺一不可。脸偏胖不合格。详见 [[../01_长期记忆/重要人物与数字资产#双图核验清单（必用）]]。

- 原 4K 锚点始终负责身份；脸型 8 格只校准瘦削椭圆脸与下颌线；视频拆帧只负责表情、皮肤、眼神、动作和姿态参考。
- 丁美霞笑容只允许自然微笑，禁止咧嘴笑、露齿大笑、张嘴笑或笑容强度逐渐放大。
- 丁美霞皮肤使用状态参考 S01、S07、S08 辅助校准：紧致健康、肤色自然均匀、眼下清爽、有细腻真实纹理；不得用这些截帧替代主锚点的身份数据。
- 推近、变焦、人物走近镜头或最终落到半身 / 面部特写时，不能只验首帧；必须抽取推近开始、50%、80% 和最终近景帧，逐帧检查脸颊、下颌、眼下和颈部松弛度。任一近景出现松弛、眼袋/泪沟、皱纹加深或视觉年龄变老，整镜不合格。
- OpenRouter + HappyHorse 项目使用 [[OpenRouter HappyHorse丁美霞视频工作流]]。

## 下载注意

- 任务要求实际下载 IMA 文件时，按 [[../01_长期记忆/工具与环境注意事项#网络]] 在下载前提醒用户处理 VPN。
- 用户要求“只发链接”时，不提示 VPN、不执行下载；生成成功后保存任务 ID，只返回可点击结果链接。
