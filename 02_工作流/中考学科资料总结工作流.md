# 中考学科全套资料 · 标准化生成工作流（全科通用）

> [!summary] 终极一句话（永久复用）
> **定本地考情 → 分层重难点 → 提炼固定题型模型 → 统一阅卷满分话术 → 补全漏解场景 → 配套满分范例 → 梯度刷题方案 → 分阶段复习规划 → 冲刺提速体系**

> [!important] 定位
> 不是普通知识点堆砌，而是**完全适配本地命题、可落地刷题、应试提分**的标准化生产流程。  
> 盐城物理／化学／数学已按同一套逻辑落地，形成「中考三科标准化资料生产工作流」，可复用所有学科。

> [!tip] 与相邻工作流分工
> - [[中考学科知识库建设工作流]]：IMA／课标／知识点总表／单元口述地图（「学了什么」）。  
> - **本工作流**：本地中考**精准提分资料包生产**（「怎么考、怎么答、怎么刷」）。  
> - [[孩子单元学习复讲评估工作流]]：单章 `00`–`09` 复讲闭环。  
> - 交付仓库：`/Users/wangzirui/孩子们的知识点`；库内入口：`00_HOME/中考学科资料总结工作流.md`。

## 零、核心原则

1. **不看全国、只看本市**（及同体系本省卷）；版本／章节不匹配一律剔除。  
2. **临场做题 → 套模板做题**；模板必须来自本地近5年大题统计。  
3. **主观题不自己造句**：统一阅卷踩点句式。  
4. **复习时间按分值权重分配**，不平均用力。  
5. 选择填空可借二级结论提速；**解答大题必须完整推导**（数学／理化实验话术同理）。

## 一、九步生产流程（必须按序）

### 第一步：定版本、定考情、定试卷结构（地基层）

1. 锁定地区（如：江苏盐城）  
2. 锁定教材版本与完整单元／章框架（须用户或学校确认）  
3. 锁定试卷结构（题型、大题排布、满分／时长）  
4. 锁定难度比例与得分优先级（如数学约 7∶2∶1）  

**输出**：`{教材}学习地图.md`（完整目录＋资料包状态）。  
**目的**：杜绝网上乱资料，内容贴合本地考场。

盐城已确认锚点：

| 数学 | 苏科版 30 单元；150 分／120 分钟；九步全套已齐 | `…/数学/盐城中考数学-全套资料总清单.md` |

### 第二步：按分值权重分层，排序重难点

按本地近5年真题分值，至少分三层（可加「扣分重灾区」为第四层）：

1. **第一梯队**（压轴核心）  
2. **第二梯队**（中档必考）  
3. **第三梯队**（基础送分）  

**输出**：`江苏中考{学科}-重点难点与提分策略.md`（含一句复习优先级）。  
**逻辑**：不平均用力，按考场分值分配时间。

示例：化学酸碱盐＞金属＞溶液；物理电学＞浮力压强＞机械效率；数学二次函数＞圆＞相似＞解直角三角形；英语阅读填空＞写作＞完形＞从句／完成时＞人机。

### 第三步：提炼本地固定题型模板（最核心价值）

统计近5年本地所有大题，提炼固定出题模型：

1. 基础大题固定模板  
2. 中档大题固定模板  
3. 高频模型（几何／实验／推断等）  
4. 压轴／综合题模板  
5. 本地特色题型流程（如数学新定义、物理阅读压轴）  

**输出**：`江苏中考{学科}-…模板与…话术.md` 及学科专项模型清单。  
**本质**：把临场做题变成套模板做题。

### 第四步：统一阅卷标准，生成满分书写话术

对标本省阅卷踩分规则：

1. 辅助线／实验操作标准话术  
2. 证明／推断标准判定格式  
3. 分类讨论标准结尾（如「综上所述」）  
4. 硬性检验项（分式方程检验、应用题答、控制变量前提等）  
5. 压轴存在性／动态电路等固定书写流程  

**解决**：会做但步骤扣分、书写不规范。

### 第五步：提炼漏分解场景（攻克压轴丢分重灾区）

整理所有多解／易漏情况（分类讨论体系）：

- 数学：等腰／直角／平行四边形三类；圆弦、动点、折叠多解  
- 物理／化学：按学科补「易漏条件／多情形」清单  

**输出**：分类讨论／漏解场景清单。  
**核心**：会做但漏解、压轴拿不满分。

### 第六步：配套满分例题范本

高频题型各配 **1 道本地风格例题＋满分标准答案**（可抄写）。  
**输出**：各专题满分范本／合订页。

### 第七步：搭建刷题梯度

1. 最高优先：本市近5年真题  
2. 适配中档：同风格邻市（盐城语境：泰州、扬州）  
3. 拔高：南通、苏州等  
4. 基础手感：偏基础市卷  

**明确拒绝**：全国卷／教材版本不匹配题型包（如全国版五三）。  
**输出**：`江苏中考{学科}-真题推荐与刷题规划.md`＋`{地市}近5年…必考大题题型清单.md`。

### 第八步：制定分阶段复习落地计划

1. 一轮：基础框架＋规范书写  
2. 二轮：专题模型＋大题模板突破  
3. 冲刺：整套模考＋错题溯源  
4. 考前 3 天：模板复盘＋易错点突击  

**输出**：分阶段使用规划、每周计划、每日打卡清单（可按学科裁剪）。

### 第九步：附加提速体系（解决做题慢）

配套产出：

1. 解题速度提升专项方案  
2. 考场时间分配参考  
3. 模考计时跟踪表（可打印）
